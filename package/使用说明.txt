========================================
 皖美AI 视频生成调试工具（绿色免安装版）
========================================

一、这是什么
  本工具用于测试平台 Seedance 视频生成 API：文生视频 / 图生视频（首帧、
  首尾帧）、多模态参考素材，直接走平台真实计费链路（创建即预冻结、终态
  结算多退少补）。

二、怎么用
  1. 双击「启动视频工具.bat」，等待几秒自动打开浏览器页面
     （地址 http://127.0.0.1:8501，端口被占用会自动顺延）
  2. 侧边栏填两个东西：
     - API Key：sk-wm- 开头，在平台客户控制台「令牌管理 → 视频生成」签发
     - API Base URL：测试环境填
         http://117.57.203.251:6080/prod-api/cloud/video/api/api/v3
       （默认值是本地联调地址 localhost:8080，连远程必须改）
  3. 选模型（2.5 主推 / 2.0 多模态）、画面比例、分辨率（影响计费档位）、
     时长（2.5 最长 30 秒），填 prompt，点「生成视频」
  4. 拖图上传会自动经 Cloudflare 隧道转成公网 URL（界面出现
     「已通过 Tunnel 暴露为公网 URL」即成功），这是原生图生视频方式，
     不需要 base64
  5. 生成成功的视频自动存档到 videos\ 目录（上游直链 24 小时过期，
     本地留档不丢）

三、注意事项
  - 每次创建任务都走真实计费，调试期建议：短时长 + 480p + 小额 Key
  - 需要能访问 *.cloudflare.com（隧道用）；公司网络若封锁需代理
  - 工具所有数据（Key 记忆、任务历史、视频存档）都在本文件夹内，
    删文件夹即彻底清除

四、常见问题
  - 浏览器打开后侧边栏底部没有绿色 Tunnel 圆点
    → 出口网络到 *.cloudflare.com 不通，换网络/代理
  - 报 401 token 无效
    → Key 没填对，或 Base URL 的两段 api 写错
  - 图生视频报 InvalidParameter.URL
    → 重新拖一次图生成新 URL（应用重启后旧 URL 失效）
  - 连接拒绝/超时
    → 确认后端服务可达（测试环境网关 117.57.203.251:6080）

五、更新方法
  发新版本时只需覆盖本目录里的 app.py（和 tunnel.py，若改过），
  重启工具即可，不用重新解压整个包。
